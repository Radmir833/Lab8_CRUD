# Лабораторная работа №14

Откройте Lab8_CRUD.slnx в Visual Studio и выберите «Тест → Запустить все тесты».
Можно также выполнить dotnet test Lab8_CRUD.slnx. Нужны .NET Framework 4.7.2
и доступ к NuGet при первом восстановлении пакетов. Для тестов SQL Server не требуется.
Для запуска формы используйте локальный SQL Server с базой StudentDB_Lab10.
