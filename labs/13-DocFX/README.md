# Lab8_CRUD

Windows Forms приложение для учёта студентов. Оно загружает записи из SQL Server, ищет студентов по ФИО и позволяет добавлять, изменять или удалять записи. Видимые строки можно экспортировать в CSV.

## Среда и запуск

1. Установите Visual Studio с рабочей нагрузкой для классических приложений .NET, пакет разработчика .NET Framework 4.7.2 и локальный SQL Server.
2. Откройте решение **Lab8_CRUD.slnx** и нажмите F5.
3. При первом запуске приложение создаёт **StudentDB_Lab10** и таблицу **Students** в локальном экземпляре SQL Server. Для этого у учётной записи Windows должно быть разрешение на создание базы данных.
4. Если база подготовлена отдельно, укажите строку подключения к ней в переменной **LAB8_CONNECTION_STRING**. В таблице **Students** должны быть столбцы **Id**, **FullName**, **Age**, **GroupName**, **AverageGrade**.

## Работа с программой

Чтобы создать запись, заполните ФИО, возраст, группу и средний балл, затем нажмите «Добавить». Для правки или удаления выберите студента в таблице. Кнопка «Показать лог» открывает журнал **errors.log** в Блокноте.

## Документация и исходники

- **Form1.cs** содержит обработчики формы и запросы ADO.NET.
- **Logger.cs** записывает успешные и ошибочные операции.
- **Lab8_CRUD.xml** генерируется при сборке в каталоге **bin/Debug** или **bin/Release**.
- Команда **docfx docfx.json** создаёт HTML-документацию в каталоге **_site**.
- История версий находится в **CHANGELOG.md**. Как вносить изменения, описано в **CONTRIBUTING.md**.
