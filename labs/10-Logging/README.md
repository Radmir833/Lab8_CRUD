# Лабораторная работа №10

Откройте Lab8_CRUD.slnx в Visual Studio с .NET Framework 4.7.2 и нажмите F5.
При первом запуске локальный SQL Server создаст StudentDB_Lab10 и таблицу Students.
Можно указать готовую тестовую базу через LAB8_CONNECTION_STRING.

Добавьте тестового студента и повторите добавление с тем же ФИО, чтобы увидеть предупреждение.
Кнопка «Показать лог» открывает errors.log по месту сборки. Пример проверенного журнала находится в отчёте.
