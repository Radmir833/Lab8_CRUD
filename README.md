# Lab8_CRUD

Учебное приложение Windows Forms для учёта студентов. В таблице можно просматривать студентов, а по полю «Поиск по ФИО» — фильтровать список. Форма позволяет добавлять, редактировать и удалять записи.

## Запуск

1. Установите Visual Studio с компонентами .NET Framework 4.7.2 Desktop Development и локальный SQL Server.
2. Откройте `Lab8_CRUD.slnx` и запустите проект клавишей F5. По умолчанию подключение выполняется к локальному экземпляру SQL Server под учётной записью Windows. При первом запуске создаются `StudentsDB` и таблица `Students`.
3. Для другой базы задайте полную строку подключения через переменную `LAB8_CONNECTION_STRING`. Таблица `Students` должна существовать в указанной БД.
